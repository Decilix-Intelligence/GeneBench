# 声明歧义的实测影响（卡 2.2b 第二交付物）

**三份互不知情的独立实现**，只依据 `ops/specs/backtest_contract.md` 写，不读 qlib 源码、不接触 qlib（输入是一份纯 parquet）。

> 这份文件的用途：清单里凡是在这里**表现出分歧**的条目，**S7 出题时必须在题面里写清**，否则 agent 会撞上同样的歧义，而我们会把「声明不清」误判成「agent 做错」。

**怎么读这两列**：

- 「B 互相最大差」≈「A vs B 最大差」 → **声明本身欠定**，与 A 是不是 qlib 无关；
- 「B 互相」很小而「A vs B」很大 → **A 在某个歧义上做了与三份 B 都不同的选择**。

`total_cost` 属于后者：三份 B 聚在 0.439–0.457，A 是 0.373，B 互相只差 3.89% 而 A vs B 差 **18.33%**。费用是净收益的最大杠杆，这一条要单独查。

`ann_return_net` 的 96% **不是**「实现差了 96%」：它是 `gross(≈0.057) − 成本拖累(≈0.05)` 的**小差值**，相对误差被结构性放大。**这是关于指标本身的发现** —— 净收益不适合直接作 ε 的标定对象。

## 2. 三份实现各自怎么选的

| 歧义 | B1 | B2 | B3 | 是否分叉 |
| --- | --- | --- | --- | :---: |
| **A-2 买哪几只** | 补齐到 topk（从可买候选按信号往下取） | 补齐到 topk（= topk − 卖出后持仓数） | 补齐到 topk（= 卖出数 + 因不可交易留下的空缺） | ⚠ **是** |
| **A-3 资金如何分配** | 可用现金等额分配（**先写成「总资产/topk」，自查发现现金堆到 3.6% 后改的**） | 可用现金在本次买入标的间等额分配 | 可用现金等额分配（cash / n_buy） | ⚠ **是** |
| **A-4 是否每日再平衡** | 否 | 否 | 否 | 一致 |
| **A-5 换手分母** | 当日**交易前**总资产 | 期初总资产 | **上一交易日收盘**的总资产 | ⚠ **是** |
| **A-6 单边/双边定义** | 单边 = 卖出额/TA；双边 = (买+卖)/TA | 同左（照声明 §6 字面） | 同左 | ⚠ **是** |
| **A-7 可交易性挡在哪一步** | 先在**全部有效信号的成分股**上排 topk，执行环节再过滤 | topk 先按信号选出（**不看可交易性**），执行阶段再剔除 | **从当日可交易的集合里**选 topk | ⚠ **是** |
| **A-8 要卖的票不可交易** | 跳过继续持有 | 跳过 | 跳过 | ⚠ **是** |
| **A-10 min_cost 粒度** | 每标的每日一笔 | 每标的**每方向**每日一笔 | 每标的每日一笔 | ⚠ **是** |
| **A-11 整手取整** | 用**原始价**向下取整 | 向下取整 | 向下取整(floor) | ⚠ **是** |
| **A-12 建仓/清仓** | 首日建满，末日不清仓 | 同左 | 同左 | 一致 |
| **A-13 信号缺失** | 不参与排序；**持有则视为已跌出 topk** | 不参与排序 | 买入侧不参与排序 | ⚠ **是** |
| **A-14 收益率分母** | 含现金的总资产 | 含现金 | 含现金 | ⚠ **是** |
| **A-15 T+1 粒度** | 次一交易日 | 次一交易日 | 次一交易日 | 一致 |

**分叉最明确的两条**：

- **A-7 可交易性挡在哪一步** —— B3 从**当日可交易集合**里选 topk，B1/B2 先在全部有信号的成分股上排 topk、执行环节再剔除。B1 的理由是「跌出 topk 是信号事件，不该被流动性污染，否则一只涨停的持仓会被判成跌出 topk」；B3 的理由是「持仓恒为 topk 只」。**两种都成立，持仓数与权重完全不同。**
- **A-5 换手分母** —— 三份各写了一种措辞（交易前总资产 / 期初总资产 / 上一交易日收盘总资产）。B1 实测两种口径差 3e-4（0.10412965 vs 0.10416044），**量上可忽略，但三个人从同一句话读出三种意思本身就是声明不清的证据**。

**A-3 曾经分叉，被实现者自己修掉了**：B1 最初按「交易前总资产 / topk」定目标金额，自查发现现金稳态堆到总资产的 3.6%（卖出回款系统性大于买入支出），等于凭空给组合加了 3.6% 现金仓位、稀释收益，于是改成与 B2/B3 一致的「可用现金等额分配」。**这条值得记**：一个歧义可以在实现内部被数值自查发现并收敛，但那依赖实现者去查现金占比 —— agent 不一定会查。

## 3. 判据与结论

按卡 2.2b 的三条约束（`reference/epsilon_dual.py` 里写死的）：

- 相对差 > **5%** → 不写成 ε，停下汇报；
- 相对差 < 浮点噪声地板 **1e-13** → 标 invalid；
- A 与 B 完全相同 → 标「无实现自由度」，**不许用别的指标的 ε 代填**。

| 状态 | 指标 |
| --- | --- |
| ✅ 可标定 | ['ann_vol_net', 'win_rate_net'] |
| ⚠ 超阈、停下汇报 | ['ann_return_gross', 'ann_return_net', 'max_drawdown_net', 'sharpe_net', 'total_cost', 'turnover_one_way_mean', 'turnover_two_way_mean'] |
| 无实现自由度 | （无） |
| 低于噪声地板 | （无） |

**ε 不可用**（`usable = False`）。7 个指标超过 5% 阈值，按签字要求**停下汇报，不把它们写成 ε** —— 过宽的 ε 会让 S7 失去判别力。

**这不是失败，是这张卡该有的产出**：它证明了当前声明的欠定程度足以让三份认真的实现在毛收益上差 **10.8%**、在换手上差 **5.8%**。ε 要能用，得先把声明收紧到这些分歧消失为止；而收紧声明的清单，就是上面第 2 节。

### weekly / monthly 为什么 `usable = false`（原因栏）

`epsilon_dual_weekly.json` / `epsilon_dual_monthly.json` 两档都是 `usable = false`，
超 5% 阈、按签字要求「停下汇报」的指标是：

| 档 | `implausible`（停下汇报，不写成 ε） |
| --- | --- |
| `weekly` | `ann_return_gross`（5.233%） |
| `monthly` | `ann_return_gross`（19.252%）、`sharpe_net`（12.839%）、`total_cost`（9.090%） |

**已知原因之一：N-38 —— 三份实现对「首日是否强制建仓」的读法不一致**
（`ops/tickets.md` 附录 Z，状态：**登记缓办**）。取证：
`impl_v2_b1.py:153 keep[0] = True` 与 `impl_v2_b2.py:147 mask[0] = True` 强制把窗口首日置为调仓日，
而 `impl_v2_b3.py:126 rebalance_days()` **没有这一步**。
日频下三份掩码都是全 True，这处分歧**不可见** —— 2026-09-03 materiality screen 实测
`first_rebalance_day` @ daily 为 **immaterial（9/9 项逐位相同）**；
**周频/月频才显现**，且它落在**建仓时点**上，与 `ann_return_gross` 超阈同向。
这与上表「v2 实现者撞上的新歧义」首行的「首次建仓时点」是同一件事的两面：
那里记的是**声明缺字段**（已升为必填 `first_rebalance_day`），这里记的是**三份既有实现至今没对齐**。

**因此这两档的 ε 带在查清 N-38 之前不可解释**：撑大它的可能不是「实现自由度」，
而是一处没对齐的约定 —— 那样标出来的 ε 会把「约定没写清」当成「实现本来就该差这么多」卖给 S7。
**v1.1 做周频/月频前必须先查。**

**机器可读的原因栏目前是缺的**：`reference/epsilon_dual.py` 只在单档/合并那条路径（`:275-302`）
生成 `outstanding`；多档路径（`:179` 的 `"usable": not bad`）只写 `usable`、不写原因，
所以 `epsilon_dual_{weekly,monthly}.json` 里**没有 `outstanding` 字段**。
补它要改既有代码，随 v1.1 那次一并做；在那之前，本节就是这两档的原因栏。

## 6. A↔B 的**未归因残差** 22.69%，与**知情保留**的欠定项 A-1

参考回测 A（qlib TopkDropout）与三份独立实现 B：

| | 值 |
| --- | ---: |
| `turnover_two_way_mean` 差 | **−0.51%** |
| `ann_return_gross` 差 | **+22.69%** |

**换掉的金额几乎一样、换的标的不同。**

**这 22.69% 是「未归因残差」：成因未知。** 本节此前写的是「定位到 A-1」，
**该归因已于 2026-09-03 撤回**（见下）。

**已排除的解释**（都查过了）：费用口径（逐笔与声明一致到 9 位小数）、
`total_cost` 取数通道（N-28，已修，18.11% → 3.50%）、
`risk_degree`（设为 1.0 后换手差 −1.04% → −0.51%，毛收益反而略升），
**以及 `sell_rule`（A-1）本身 —— 由隔离实验排除，见 6.1。**

> ⚠ **这 22.69% 是未归因残差，不是未解决缺陷，也不是 bug。**
> 它仍然是**知情保留**的：A 与 B 完全收敛没有独立价值（`daily` 档 ε 已 usable）。
> `ops/test_underdetermination_guard.py` 锁的是**它仍然存在**；
> 它消失说明有人改了 A 或 B，**先去查什么变了**。

### 6.1 隔离实验：A-1 只能解释 0.4%，不是 22.69%

原结论「剩余差异定位到 A-1 / A-2」是**排除法**得到的 —— 排除掉上面三项之后，
把剩余项安给了 A-1，而 **A-1 从未被单独跑过**。

2026-09-03 的 materiality screen 做了那个隔离实验：在**同一份实现内部**切换
`sell_rule` 的两种读法（`dropped_from_target` ↔ `worst_n_drop`），其余一切不变。

| 实现 | `ann_return_gross` 相对差 | 超出 daily ε 带的指标数 | 判定 |
| --- | ---: | ---: | --- |
| B1 | **0.45%** | 5 | **material** |
| B2 | **0.38%** | 6 | **material** |
| B3 | **0.38%** | 6 | **material** |

（daily ε = **0.237%**。产物：`ops/reports/materiality_s7_sell_rule.json`）

**0.4% 与 22.69% 相差约 50 倍 —— `sell_rule` 解释不了那个残差。**

> **screen 的判别力自检**：同一套 screen 跑 `first_rebalance_day` @ daily 判
> **immaterial**（9/9 项逐位相同）。
> **Gate 0**：未打补丁的沙箱副本复现快照，最大相对差 1.5e-14（BLAS 归约序），
> 产物**不是逐字节可复现**。**Gate 1**：打了补丁、开关各取原读法 →
> 与 Gate 0 **逐位相同**，补丁中性已被证明。

### 6.2 A-1 仍然不定死（裁定维持）

**签字裁定（2026-09-01）：不定死 A-1；2026-09-03 复核后维持。**
qlib 卖「持仓中信号最差的 `n_drop` 只」，三份 B 卖「已跌出当日目标组合的」——
**两种读法都合理**，声明不裁决哪一种。它是一条**有实测背书的高质量欠定样本**：
背书现在来自**它自己的隔离实验**（material，三份实现一致判定），
而不再来自「它解释了 22.69%」。**A-1 仍是知情保留的欠定项**，只是**不再是那个数的成因**。

**方法论**：排除法不构成归因 —— 排除了三个候选，不等于第四个候选成立。
剩余项的大小等于「全部未查项之和」，把它当作某个单一候选的效应，
等于默认其余未查项之和为零，而这个假设从未被检验。
只有隔离实验（其余不变、单切一个开关）测得的效应才算归因；
排除法得到的东西只能报成「未归因残差」。
