# 回测声明的欠定性：三份独立实现的实证

> 与 `operator_semantics_conflicts.md` **并列**。两份是同一论点的两端：
> **因子名不足以确定计算，回测声明不足以确定结果。**
> 两端的分歧在产物层面都表现为「跑通了、有数、看着正常」。

本文数据来自 **v2（声明修订后）**，调仓频率 daily。

## 方法

**独立性由结构保证，不是由承诺保证** —— 这是本实验唯一真正的风险，处理方式有三层：

1. **声明先落盘，再开始实现。** 顺序是硬要求。声明（`ops/specs/backtest_contract.md`）写完并归档之后，实现者才拿到它。
2. **实现者拿不到参考实现。** 输入是一份**纯 parquet**（日期/代码/后复权价/复权因子/成分标志/有价标志/退市标志/信号），**不需要也接触不到 qlib**。「不看 qlib 源码」因此不是一条自觉遵守的规则，而是**做不到**。
3. **三份实现互不知情。** 它们并行产生，彼此看不到对方的代码与结果。

凡是声明没写死的点，实现者**自行决定并记录选择与理由**，**不去查别人怎么做的**。计算结构要求向量化，与参考实现的逐日循环结构不同 —— **不同的计算结构才能暴露实现自由度**。

## 结果

同一份声明、同一份信号、同一段窗口（csi300，2019-01-02 … 2026-07-03，1,818 个交易日）：

| 指标 | B1 | B2 | B3 | **三份 B 互相最大差** |
| --- | ---: | ---: | ---: | ---: |
| `ann_return_gross` | 0.055349 | 0.055436 | 0.055436 | **0.16%** |
| `sharpe_net` | 0.12319 | 0.12355 | 0.12355 | **0.29%** |
| `total_cost` | 0.45565 | 0.45535 | 0.45535 | **0.07%** |
| `ann_vol_net` | 0.23206 | 0.23207 | 0.23207 | **0.00%** |
| `max_drawdown_net` | -0.52912 | -0.52906 | -0.52906 | **0.01%** |
| `turnover_two_way_mean` | 0.20746 | 0.20747 | 0.20747 | **0.00%** |
| `win_rate_net` | 0.4989 | 0.4989 | 0.4989 | **0.00%** |

**三份互不知情的实现，在毛收益上互相差 0.16%，在双边换手上互相差 0.00%。**
三份都能跑通、都产出完整指标、数值分布都正常，**没有任何一份会自己报错**。

分歧的来源是声明里**没写死**的点：资金如何分配到买入标的、可交易性在选股层还是执行层生效、换手的分母取哪一个总资产、以及（首轮最致命的一条）**调仓频率根本没写**。

## A↔B 的未归因残差

上表是 **B↔B**（三份独立实现互相之间）。另有一个数量级完全不同的差异来自 **A↔B**
（参考实现 A = qlib TopkDropout，对三份 B 的均值）：

| | 值 |
| --- | ---: |
| `turnover_two_way_mean` 差 | **−0.51%** |
| `ann_return_gross` 差 | **+22.69%** |

**这个 22.69% 是「未归因残差」** —— 它的成因**没有被任何隔离实验确定过**。
此前的文档（本文、卡 2.2b、声明 §9、gold 数据卡）把它归给声明里的欠定项
**A-1**（`n_drop` 的卖出选择），**该归因已于 2026-09-03 撤回**：
它是**排除法**的产物（排除了费用口径与 `risk_degree`），从未做过隔离实验。

**隔离实验反而把 A-1 排除了。** 2026-09-03 的 materiality screen 在**同一份实现内部**
切换 `sell_rule` 的两种读法（「卖已跌出当日目标组合的」↔「卖持仓中信号最差的 `n_drop` 只」），
其余一切不变，三份 B 的 `ann_return_gross` 相对差只有 **0.38%–0.45%**
（daily ε = 0.237%；B1 5 项 / B2 6 项 / B3 6 项指标超带 → 判定 **material**）。

**0.4% 与 22.69% 相差约 50 倍 —— `sell_rule` 解释不了这个残差。**
它确实是 material 的（真的影响结果，仍是合格的 S7 题源），但它**不是** 22.69% 的成因。

> **screen 的判别力自检**：同一套 screen 跑 `first_rebalance_day` @ daily 判 **immaterial**
> （9/9 项逐位相同），说明它不是「什么都判 material」。
> **Gate 0**：未打补丁的沙箱副本复现快照，最大相对差 1.5e-14（BLAS 归约序）——
> 产物**不是逐字节可复现**，判据用相对差。
> **Gate 1**：打了补丁、两个开关各取自己的原读法 → 与 Gate 0 **逐位相同**，补丁中性已被证明。

**残差仍然是知情保留的。** 它不是待修的 bug；A 与 B 完全收敛也没有独立价值
（daily 档 ε 已 usable）。撤回归因只改变了一件事：
**我们不再声称知道它由什么造成**，也不再拿 A-1 当它的解释。

## 结论

**一份回测声明，即便写明了策略类型、持仓数、换手上限、费率、涨跌停阈值、结算规则、初始资金与全部指标公式，仍不足以确定回测结果。**

这与因子层的发现是同一件事的两端：

| | 因子层 | 回测层 |
| --- | --- | --- |
| 不足以确定计算的东西 | 因子**名**与**表达式** | 回测**声明** |
| 分歧的来源 | 算子语义未绑定值域；实现读错输入字段 | 声明未覆盖的执行细节 |
| 产物层面的表现 | 能算出数、跑得通、数值正常 | 同左 |
| 照出来的唯一手段 | 拿另一个独立实现去对 | 同左 |

**方法论后果**：可复现的量化研究协议必须把「实现自由度」当成**一等公民**来度量，而不是假定它可以忽略。具体到评测：判「被测系统的回测是否复现了参考结果」时，容差不能来自浮点噪声（那会要求比特级相等），而必须来自**两份独立实现同一份声明的自然分歧** —— 因为被测系统正是这样的第二份实现。

**一个反面教训值得单独记**：我们最初打算用「同一份代码在不同库版本下重跑的极差」标定容差。实测跨 4 个 numpy/pandas 组合（含 pandas 1.5.3 → 2.2.3 的大版本跨度）最大相对极差只有 **8.53e-14**，即纯 float64 舍入。照它定容差等于要求被测系统与参考实现**比特级相等** —— 而它在数值上看起来「已经标定过了」。

## 方法论：排除法不构成归因

「排除了 X、Y、Z，所以是 W」——**这不是归因，是给剩余项起名字。**
它把「我们没查过的一切」压缩成一个已命名的候选，然后停止查。

A↔B 的 22.69% 正是这样被安到 A-1 头上的：查过费用口径（逐笔与声明一致到 9 位小数）、
查过 `total_cost` 取数通道（N-28，已修）、查过 `risk_degree`（改为 1.0），
剩下的差异就被记成「定位到 A-1 / A-2」—— 而 **A-1 从未被单独跑过一次**。

**只有隔离实验才算归因**：把候选项做成一个可切换的开关，其余一切保持不变
（同一份实现、同一份输入、同一段窗口、同一份快照），两个读法各跑一遍，量它自己的效应。
一旦真去做，A-1 的单独效应就是 **0.38%–0.45%**，与 22.69% 差 **约 50 倍** —— 归因当场垮掉。

这条差别有两个可检验的推论，本例中都兑现了：

1. **排除法给不出量级约束。** 剩余项的大小等于「全部未查项之和」。
   把它当成某个单一候选的效应，等于默认其余未查项之和为零 —— 这个假设从来没被检验过。
2. **排除法会自我封闭。** 剩余项一旦有了名字，它就不再像个待解问题，
   于是**没有人会再去做那个隔离实验**。本例中这个状态维持了两天，
   并已扩散进四处文档与一条守门测试 —— 错误归因的传播速度和正确结论一样快。

**这一条值得写进论文的方法学部分。** 可复现性研究里「我们把差异定位到 X」这类陈述，
必须区分**排除法得到的剩余项**与**隔离实验测得的效应**：
前者只能报成「未归因残差」，且必须同时列出**已被排除的候选及其实测单独效应**
（本例：`sell_rule` 0.38%–0.45%）。
**排除了三个候选，不等于第四个候选成立。**
