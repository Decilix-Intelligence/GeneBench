## F-1 秩相关的算法

> 逐交易日在截面上算 Spearman，再对时间序列取分布（与 IC 的算法同构，
> 也与 Table B 的 S4 口径一致）。

tie 用**平均法**——与第一批冻结项第 4 条里"平局平均法"一致，此处不另立口径。

**落地**：`reference/factor_crosscheck.py::_row_spearman()`。
它先 `DataFrame.rank(axis=1)`（平局即平均法）再逐行 Pearson，与
`scipy.stats.spearmanr` 定义等价但避免 43 万次 Python 级调用；
`ops/test_factor_exec.py::test_vectorized_spearman_matches_scipy_on_real_data`
在**带结的真实 gold 数据**上逐日对照 scipy，是这条实现的唯一硬证据。

## F-2 τ 的取法

> τ 取"全因子 × 全交易日"这个二维分布的 P10。
> **不要先对时间平均再取分位**——那会把某些日子完全失配的因子藏在均值里，
> 而 S3 的 Fid% 判的是"这一天这个因子算对没有"。

判定粒度 = (因子, 交易日)，所以标定粒度也必须是 (因子, 交易日)。

## F-3 三个数一起报，供签字参考

1. 逐日分布 P10（**= τ**）
2. 按因子聚合（对时间取均值）后的因子级 P10
3. 两者的差

> 差很大说明失配集中在少数日子而非均匀分布，那是另一个故事，要写进标定报告。

## F-4 tie 与常数因子必须在标定前处理

> Spearman 对结敏感：一个几乎处处常数的因子，两个实现都输出常数，
> 秩相关是 NaN 或接近 1，**两种情况都会毒化 τ 的分布尾部**。

判据（逐 (因子, 日)）：

```
degenerate  <=>  min(唯一值数_A, 唯一值数_B) < 5% × 截面有效标的数
             或  截面有效标的数 < 20
```

**阈值来源**（要求"阈值来源一并记录"）：签字人 2026-09-01 指定 **5%**，
与 **N-17「因子退化检测」同源**——那条也是拿"因子在截面上还剩多少分辨力"当判据。

⚠ **这个 5% 与 N-17 自己的上线阈值不是同一个数**：N-17 受 D-04 制度约束，
它的阈值必须取 792 条可执行因子**实测覆盖率分布的 P5**，不许拍。
这里的 5% 是**标定期的样本清洗阈值**，用签字指定值；
标定报告同时报出**实测的唯一值比例分布**，好让签字人看见 5% 落在分布的什么位置。

## F-5 剔除率要按两个维度报

> 按因子与按日各报一次。若某后端的 degenerate 率显著更高，

## E-1 ε 的随机性来源必须写清，极差为 0 要停下

> ε 是回测指标的复现容差，五种子重跑的极差 ×1.5。
> **如果参考回测在同一 gold 信号上是完全确定性的（无随机初始化、无采样），
> 那么五种子的极差会是 0，此时 ε=0 不是标定成功而是标定失效**——
> 真正的容差应来自跨环境/跨库版本的浮点差异。
> 若发现极差为 0，**停下汇报**，改用另一种标定源
> （同一 gold 在两台机器或两个 numpy/pandas 版本下的差异），
> **不要直接把 ε 设成 0 或拍一个小数**。

**这条是一个"绿得可疑"的判据**，与 D-01/D-02/D-03 同形：
所有可见信号都是绿的（五次跑出一模一样的数），而实际上标定过程什么都没测到。
卡 2.2 实现 ε 标定时，**第一步就是先确认参考回测里到底有没有随机性来源**，
把答案写进标定报告，而不是跑完五次看见 0 再解释。

**停下汇报的触发条件（写死在代码里，不靠自觉）**：
五种子极差 == 0（或小于 float64 的表示噪声）→ 抛错并打印本条，不产出 `calibration.json`。
