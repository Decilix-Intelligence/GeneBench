# 卡 2.5：公共数据通道（2026-09-04 开卡，与 M4 并行）

**代码**：`snapshots/public/`（新增；复用卡 2.1a 的 `dump_bin` 管线）。
**跑在**：f01（数据面）。**不动 runner** —— 本卡与 M4 并行，两边不共享可写状态。
**排期**：与 M5 并行（不依赖评分器）。**M6 构造验收改在公开通道上做。**

---

## 0. 目的

> **v1 Stage 赛道完全基于可再分发的公开数据**，使 benchmark 可下载、可复现、
> 可交给不同实验室跑。

私有通道（审计湖 + ChinaScope）**保留给 v2 授权赛道，并在本卡里当验证器**。
两个通道**并列，不覆盖**：公开通道建成之后，私有通道的产物原样留着，
用来核公开通道算得对不对。

**为什么这件事必须现在做**：一个跑不起来的 benchmark 不是 benchmark。
v1 的题面、gold、τ/ε 全部建立在私有湖上 —— 别的实验室拿到论文之后
**复现不了任何一个数**，而「复现不了」与「结论是错的」在读者那里区别不大。

## 3. 涨跌停推导（本卡唯一的工程量）

按板块规则从**前收盘**推：

**下表已按 2026-09-05 的实测结果改写**（原表见本节末的「原表与它错在哪」）。
实现在 `snapshots/public/limits.py`，验收在 `ops/acceptance/card_2_5_limit_oracle.py`。
**2026-01-01..07-31 全量 763,301 行，一致率 1.000000，0 行分歧。**

| 板块 / 情形 | 幅度 | 取整 | 备注 |
| --- | --- | --- | --- |
| 主板（60xxxx / 00xxxx）| 10% | 四舍五入到分 | |
| 创业板（300/301/**302**xxx）| 20% | 四舍五入 | 2020-08-24 前 10%；**302 号段是真代码** |
| 科创板（688/689xxx）| 20% | 四舍五入 | |
| 北交所（8xxxxx / 4xxxxx / **920xxx**）| 30% | **「不超过幅度」截断**（涨停向下、跌停向上）| 用四舍五入核只有 **52.4%** |
| ST / *ST（**仅主板**）| 5%，**至 2026-07-03 止** | 四舍五入 | **2026-07-06 起取消**，回到板块正常幅度 |
| ST / *ST（创业板 / 科创板）| **仍是 20%**，不收窄 | | 注册制板块不因 ST 收窄 |
| S 股（未完成股改，名字以 `S` 开头且非 ST）| 5% | | 全市场仅 `600182.SH`「S佳通」 |
| 新股（沪 / 深）| 前 **5** 个交易日无限制 | | 上市日取 `stock_basic.list_date` |
| 新股（北交所）| 前 **1** 个交易日无限制 | | **不是 5 天** |
| **退市整理期首日** | 无限制 | | 判据取 `namechange.change_reason='退市整理期'` |

**「无限制」在私有 `stk_limit` 里有三种编码**，三个交易所各一种：
深 `(999999.999, 0.01)`、沪 `(99999.999, 0.01)`、北 `(99999.99, 0.0)`。
推导侧**不产出哨兵** —— `Limits.up is None` 就是「无限制」这个语义。

**原表与它错在哪（四处，全部由 oracle 逼出来，对着文档一处都查不出）**：

| 原表写的 | 实测 | 不改的后果 |
| --- | --- | --- |
| 北交所 30%（未提取整）| 截断，不是四舍五入 | 北交所 **47.6%** 的行推错 |
| 「ST / *ST 5%」，无生效日 | 5% 带 **2026-07-06 起取消** | 冻结线前最后 18 个交易日约 **150 只票逐日推错** |
| 「新股首日与前 N 日无限制」，N 未定 | 沪深 5 天、北交所 1 天 | 北交所新股第 2–5 天被判成无限制 |
| （无此条）| 退市整理期首日无限制 | 半年里 **15 行**推错，且沪深命名相反、按名字判会整个漏掉沪市 |

**私有通道读 `stk_limit` 不受任何一条影响** —— 只有要自己推的公开通道会错，
而错的表现是 gold **照常算得出数**。这就是「私有通道在这里当验证器」的全部意义。



**用私有湖 `stk_limit` 逐行当 oracle 核**，报：

1. **一致率**；
2. **分歧清单**；
3. **逐条归因**（哪一条规则、哪一天、哪只票）。

> 私有通道在这里**当验证器**。这是本卡最重要的一条方法论：
> 我们有一份权威答案，就必须拿它逐行核推导，而不是「规则写对了应该就对」。

## 4. 停牌表示的差异

* baostock：**有行**，`tradestatus=0`；
* 我们的湖：**缺行**。

`tradability` 视图**吸收这个差异**，输出的三态不变
（`trade` / `suspend` / `no_data` —— `reference.artifact_schema.TRADABILITY_STATES`）。

**S2 全部 gold 在公开通道重算** —— S2 正是「缺行 vs 有行」这个差异的落点
（`missing_row_policy` 三档），不重算等于把两个通道的差异藏进 gold。

## 10. 重测数值的处置

**在公开通道重测**：τ、ε、全部 gold、A↔B 残差、B↔B 差、ε 频率分档。

* **结构性结论不变**：算子冲突、声明欠定、materiality、探针设计 —— 这些是关于
  **方法**的发现，不随数据源变；
* **数字以公开通道为准进论文**，私有通道数字作**对账对照列**；
* 两份实证成稿**方法与结论段不动，数字段换**。

> 这条要写死：如果重测后某个**结构性结论**变了，那不是「换了数据源」，
> 是**原来的结论本来就不稳** —— 那种情况必须单独上报，不许悄悄按新数字改结论。
