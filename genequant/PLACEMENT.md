# 投放说明（把协议工件发给被测 agent）

这份文件说清**协议工件怎么到 agent 手里**。它不是新规则 ——
每一条都来自 GeneBench 侧的两处现成定义，逐条给出处：

* 机读源：`placement/arms.yaml`（本树里的副本；原件 `genetask/arms.yaml`）——
  **臂 = 投放的工件集合 + 指令变体**，由这份配置定义，不写死在代码里；
* 每条协议自己的 `MANIFEST.json` 里的 `_placement` 一节。

---

## 1. 三条协议各挂在哪

| 协议 | 挂载点（容器内） | 题面提不提 | 是否叠逐题规则 JSON |
| --- | --- | --- | --- |
| `geneprotocol_v1` | `/task/protocol/` | **不提** | 是（四份规则 JSON 与工件同目录）|
| `geneprotocol_v1_doc` | `/task/protocol/` | **不提** | 否（只有两件只读文档）|
| `geneprotocol_v1_adapt` | `/task/adaptation/` | 只说「若存在」，不说里面有什么 | 否 |

`arms.yaml` 里每条 `artifacts` 是 `{manifest, mount, per_task_rules}`：
`manifest` 指向那条协议的封闭清单，`mount` 就是上表的挂载点去掉 `/task/` 前缀。

## 2. 三条投放纪律

### 2.1 被动存在，题面不提

协议工件**被动存在**于挂载点；题面（`INSTRUCTION.md`）一个字都不提它。
agent 是否发现并使用，由遥测字段 `validator_invoked` 记录。

这不是为了藏 —— 是为了**把一个潜在的混杂变成一个被测量的变量**。
题面里加一句「记得跑 validator」，两臂的差别就不再是「有没有这套机制」，
而变成了「有没有被提醒」，而后者是措辞效应。

### 2.2 封闭集合，落地即核

投放的文件集是**封闭**的，逐件带 sha256。少一件、多一件、sha 不符、空文件，
四种都必须红。「协议工件 = 某个目录里当时有的东西」不可接受 —— 那个目录会长东西
（跑过一次 validator 就会多出 `__pycache__`）。

按题生成的四份规则 JSON（`artifact_schema.json` / `contract.json` /
`payload_depends_on.json` / `task.json`）**按题不同**，因此不在这张封闭清单里，
它们的封闭性由投放方在自己的文件集核对里保证。

### 2.3 两臂唯一的差别就是这一个目录

做对照实验时：**语义内容两臂都给**（阶段的结构契约、题面里的口径，裸臂一样有），
剩给协议臂的只有**执行机制** —— 三态强制、validator 的结构化反馈、修复回路。

具体到文件：两臂的工作目录逐文件 sha256 相同，**唯二**允许不同的是
① 题面文件本身（措辞变体），② 协议臂多出来的这一个挂载目录。
裸臂的「独有文件集」必须为**空集** —— 这是等价判据的另一半，
只查「协议臂有什么」而不查「裸臂没有什么」，差别会从别的缝里漏进去。

## 3. 文档臂为什么要另存一份

`geneprotocol_v1_doc/` 里的 `README.md` 与 `contract.md` 与 `geneprotocol_v1/`
那两份**逐字节相同**（两份 `MANIFEST.json` 里的 sha 一看便知）。

不做成软链或指回去的理由很实在：封闭清单里的路径**相对清单自己所在的目录**，
指回另一个目录就得引入一个跨目录的相对路径，而那正是「投放了什么」这件事开始变模糊的地方。
一份副本换来一条可以逐字节核对的清单，值。

文档臂**不含** `validate_artifact.py`：它要回答的问题是「把规则写给 agent 看，够不够」，
而验证器是执行机制，那是协议臂的东西。

## 4. 适配模块与前两者的区别

`geneprotocol_v1_adapt` 挂在 `/task/adaptation/`，是**另一个干预**，不是协议的一部分变体。
它解决的是一件很窄的事：**上游交来的产物不是按本协议的口径写的**。

三条规则：源中缺失的信息**保持缺失**（不得由 agent 补全）；翻译要**声明**
（换算与字段/枚举/写法的翻译由 agent 提出，可接纳性由协议裁决）；
两张表（`unit_table.json` 单位换算、`field_map.json` 字段映射）给出已知的对照。

它与 `/task/protocol/` 的三态是**同一条规则**，只是这里的缺口来自**上游**而不是题面。

## 5. 自己搭一套投放要核的四件事

1. 挂载点与上表一致，且**题面不提**（提了就不是这个实验了）；
2. 投放的文件集与该协议 `MANIFEST.json` 的 `artifacts` **逐件 sha256 相等**；
3. 裸臂的独有文件集为**空**；
4. 按题规则 JSON 与工件放在**同一目录**（validator 用 `Path(__file__).parent` 找它们，
   `--rules-dir` 可以覆盖）。
