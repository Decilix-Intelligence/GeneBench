# FinRobot 0.1.5 在本环境里的依赖集。**这不是上游的 requirements.txt。**

# 上游 setup.py 的 install_requires 里有三样在本环境**必须不装**：
#   yfinance / tushare  —— 由 genebench_client.compat 顶替进 sys.modules（run.py 里
#                          compat.install()）。真库装进镜像就是一条绕过网关的路，
#                          而"没装"比"装了但被出向代理拦"更早、更响。
#   pandas_datareader   —— 同理（它也是取数库），上游代码路径里没人 import 它。
# 剩下的照装：它们是 import 期就要的（agent_library → functional/* → 这些库），
# 少一个 `import finrobot.agents.workflow` 就进不去。
#
# 版本策略：**钉住 pyautogen**（FinRobot 0.1.5 是照 0.2.x 的 API 写的，
# 0.4/0.9 那两代把 register_function 与 config_list 都改了），其余取解析结果，
# 实际落到镜像里的版本逐字记在 pin.json 的 resolved_deps 里。
