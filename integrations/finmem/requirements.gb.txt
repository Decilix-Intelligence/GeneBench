# FinMem 的依赖：**逐字取自上游自己的冻结清单** `.devcontainer/requirements.txt`
# （commit be814aa4…），只删了两行，删的理由写在下面。别在这里"顺手升级" ——
# 版本一动，装出来的就不是 pin.json 钉的那一份树。
#
# 删掉的两行：
#   --extra-index-url https://download.pytorch.org/whl/cpu
#   torch==2.2.0+cpu ; python_version >= "3.10" and python_version < "3.11"
# 为什么删：torch 在 FinMem 里**只经 transformers 被间接需要**，而 transformers
# 在这里只用来 `AutoTokenizer`（`puppy/agent.py::TextTruncator`），
# 且 TextTruncator 只在 config 里出现 `max_token_short` 时才实例化 —— 本接入的
# config 没有那个键（见 glue/chat_seam.py::build_chat_config 的注释），
# 所以 torch 一次都不会被加载。实测：不装 torch 时 `import puppy` 成功，
# transformers 只打一行 "None of PyTorch, TensorFlow >= 2.0, or Flax have been found"。
# 收益是镜像小了约 800 MB、构建期不依赖 download.pytorch.org 这个额外 index。
# 这是一处**已知偏离**，记在 pin.json 的 deviations 与 README「已知限制」里。
#
# 另外三个不在上游清单里、由本接入补的包（装在同一条命令里，不写进本文件，
# 见 Dockerfile）：setuptools / wheel（垫片的 build-backend 要）、pandas（垫片要）。
#
# 行尾的 `; python_version >= "3.10" and python_version < "3.11"` 标记是上游 poetry
# 导出时带的，**它是这份清单只能装在 3.10 上的原因**：在 3.12 上 pip 会把每一行
# 都判为不适用，然后安安静静地一个包都不装（"Successfully installed" 什么都没装）。
# 镜像里因此专门用 uv 装了一份 CPython 3.10（见 Dockerfile）。
